1. EXECUTIVE & ARCHITECTURAL OVERVIEW
========================================================================================
The Duck Creek Underwriting Intelligence Multi-Agent System is an enterprise-grade,
neuro-symbolic platform engineered to automate commercial property and casualty 
underwriting. The system decomposes complex, unstructured commercial insurance 
packages (ACORD forms, Statements of Values, 5-year loss history triangles, geospatial 
hazard layers) into actionable, deterministic quotes in under 15 seconds.

THE ARCHITECTURAL TRIAD:
1. Hub-and-Spoke Multi-Agent Topology: A centralized supervisor (Lead Underwriting 
   Orchestrator) coordinates 12 isolated, single-purpose worker agents via down-scoped 
   SPIFFE workload identities and an Envoy-based Agent Gateway.
2. Fractal Chain of Thought (FCoT) Orchestration: Rather than executing linear, 
   single-pass summarization, the orchestrator applies recursive, multi-scale reasoning 
   across Macro (industry/portfolio appetite), Meso (territorial/geospatial hazards & 
   building COPE), and Micro (line-item valuation, deterministic rate formulas, and 
   character-level document spans) analytical lenses.
3. Neuro-Symbolic Rating & Grounding Invariants:
   - Zero-LLM Actuarial Invariant: All mathematical pricing, debit/credit evaluations, 
     and risk scores are executed exclusively by deterministic Python algorithms 
     referencing versioned ISO tables (RuleSet v2026.3), with zero generative AI tokens 
     used in pricing calculations.
   - Mechanical Zero-Hallucination Barrier: Every synthesized claim is verified via an 
     Abstract Syntax Tree (AST) parser against the EpistemicCitationRegistry. Any claim 
     lacking a verified document span or API receipt is blocked at runtime.

2. SYSTEM TOPOLOGY & SECURITY ARCHITECTURE
========================================================================================
The architecture enforces strict decoupling between presentation, orchestration, 
specialist workers, security proxies, and enterprise data backends:

A. Presentation Tier (A2UI):
   - Browser client consuming real-time Server-Sent Events (SSE).
   - Dynamic Component Factory dynamically assembling Factor Justification Tables, 
     Quote Option Selectors, Underwriter Referral Briefs, Actuarial Trace Views, 
     and Agent Mesh Dossier Cards.

B. Security & Tool Interception Tier:
   - Agent Gateway: Envoy-based ingress/egress proxy intercepting all subagent tool calls.
   - Agent Identity (SPIFFE): Down-scopes tool capabilities per subagent 
     (e.g., intake-doc can only read PDFs; symbolic-rating has 0 network tools).

C. Orchestration Tier (Cloud Run / ADK 2.x):
   - Lead Underwriting Orchestrator coordinating sequential silent transfers.
   - Epistemic Citation Registry storing immutable document spans and API hashes.
   - Quote Lifecycle State Machine managing atomic state transitions in BigQuery.

D. Specialist Subagent Mesh (12 Workers):
   - Hub-and-spoke configuration with no worker-to-worker or worker-to-parent commanding.

E. Enterprise Google Cloud Services (9 Services):
   - GCS, Document AI, BigQuery, Apigee, Looker, Agent Gateway, Agent Identity, GKE, Cloud Run.

3. FRACTAL CHAIN OF THOUGHT (FCOT) ORCHESTRATION ENGINE
========================================================================================
The Lead Orchestrator decomposes commercial risk across 3 recursive analytical lenses:

1. MACRO APERTURE (Systemic & Appetite Lens):
   - Evaluates industry classification (NAICS 541512), underwriting appetite guides, 
     OFAC SDN sanctions clearance, CIP identity verification, and portfolio limits.

2. MESO APERTURE (Territorial & Regional Hazard Lens):
   - Evaluates municipal fire protection (ISO PPC Grades 1-10), FEMA Flood FIRMs, 
     satellite wildfire perimeter indices, and building construction COPE.

3. MICRO APERTURE (Line-Item & Mathematical Lens):
   - Evaluates Statement of Values (SOV) line-items, Document AI character bounding 
     boxes, 5-year loss history triangles, and executes deterministic actuarial formulas.

THE 4 FCOT OPERATIONAL MANDATES:
- Sequential Silent Dispatch: Orchestrator coordinates workers via silent internal 
  transfers (transfer_to_agent) to prevent premature turn exits.
- Epistemic Provenance Enforcement: Workers register findings into the shared citation 
  registry; uncited claims are blocked by the Grounding Guard.
- Neuro-Symbolic Partitioning: Generative LLMs handle text extraction and synthesis; 
  pure Python handles mathematical pricing.
- Dynamic A2UI Schema Generation: Orchestrator emits structured JSON-RPC 2.0 frames 
  streaming live UI component schemas to the client workbench.
